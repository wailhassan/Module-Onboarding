# Healthy Lifestyle Website

This is a simple informational website titled **Healthy Lifestyle**, aimed at promoting awareness of healthy living habits. The site provides concise guidance and resources through well-structured content and helpful articles.

# Features

- Clean and responsive layout
- Introduction to healthy lifestyle principles
- 3 informative articles for guidance
- Copyright footer

# Learning Objectives

- Used semantic HTML tags to structure the webpage
- Created three articles, each including a title, summary, and a link
- Checked a webpage against a wireframe layout
- Tested web code using Lighthouse
- Used version control by committing often and pushing regularly to GitHub

# Acceptance Criteria

- Semantic HTML tags are used to structure the webpage. (Done)
- The page scores 100 for Accessibility in the Lighthouse audit.(Done)
- The page header includes a title and description. (Done)
- The articles section has three unique articles, each including a title, summary, and a link.(Done)
- The page footer is fixed to the bottom of the viewport.(Done)
- The webpage is styled using a linked .css file.(Done)
- The webpage is properly committed and pushed to a branch on GitHub. (Done)
